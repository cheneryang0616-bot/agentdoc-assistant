# JVM 应用场景

## 服务端后端系统
JVM 最常见的应用场景是服务端后端系统，例如基于 Spring Boot 的微服务、电商交易系统、金融风控平台。JVM 的即时编译与垃圾回收让长跑服务稳定高效。

## 大数据与中间件
Hadoop、Spark、Kafka、Elasticsearch 等大数据与中间件都运行在 JVM 之上，依赖其成熟的并发与内存管理能力。

## Android 与桌面端
Android 应用运行在 ART/Dalvik 之上，其设计源自 JVM 思想；桌面端则有 Swing、JavaFX 等应用。

## 嵌入式与物联网
通过裁剪的 JVM 实现（如 KVM），Java 也被用于嵌入式和物联网设备。
